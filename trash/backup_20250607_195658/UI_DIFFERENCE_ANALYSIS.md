# GUI UI差分分析報告書

## 🔍 オリジナル `gui_dark_mode.py` と現在の実装との主要差分

### **1. レイアウト構造の根本的違い**

#### オリジナル構造：
```
root
├── navigation_bar (ツールバー + アイコン + タイトル)
├── main_content (2カラムレイアウト)
    ├── left_column (サイドバー: 200px固定幅)
    │   ├── header (Voice Models + 設定ボタン)
    │   ├── path_label (モデルパス表示)
    │   ├── separator (区切り線)
    │   └── scrollable_model_list (スクロール可能モデル一覧)
    └── right_column (メインコンテンツ)
        ├── title_section (タイトル)
        ├── input_section (横並び: ファイル選択 + 変換ボタン)
        ├── settings_section (2カラム: 出力設定 + ピッチ設定)
        ├── status_section (プログレスバー + ステージインジケーター)
        └── log_section (ログエリア)
```

#### 現在の実装構造：
```
root
├── toolbar (シンプルなヘッダー)
├── content_area (2カラムレイアウト)
    ├── left_column (350px固定幅)
    └── right_column (縦並び: 入力→出力→パラメータ→変換→ログ)
```

### **2. 具体的な差分ポイント**

#### **A. ナビゲーションバー**
- **オリジナル**: グラデーションアイコン + "Voice Converter" タイトル
- **現在**: シンプルなテキストのみ

#### **B. 左サイドバー**
- **オリジナル**: 
  - 固定幅200px、ダークグレー背景 `#141416`
  - "Voice Models" タイトル + 設定ボタン（⚙）
  - モデルパス表示（SF Pro Mono, 9px）
  - "Select a model" サブテキスト
  - 区切り線
- **現在**: カード形式、幅350px

#### **C. 右メインエリア**
- **オリジナル**: 
  - "Voice Converter - AI Voice Conversion" タイトル
  - **横並び入力セクション**: ファイル選択（左） + 変換ボタン（右）
  - **2カラム設定**: 出力設定（左） + ピッチ設定（右）
  - ステージインジケーター（7段階の円形プログレス）
- **現在**: 全て縦並び、カード形式

#### **D. 入力セクションの重要な違い**
- **オリジナル**: "Input & Convert" カード内で横並び配置
  - 左: "Choose Audio File" ボタン + ファイル情報
  - 右: "Start\nConversion" ボタン（120x50px）
- **現在**: 縦並び配置

#### **E. 設定セクションの違い**
- **オリジナル**: "Settings" カード内で2カラム
  - 左カラム: 出力ディレクトリ + ファイル名設定
  - 右カラム: ピッチ調整スライダー
- **現在**: Enhanced mode表示のみ

#### **F. ステージインジケーター**
- **オリジナル**: 7つの円形インジケーターが水平配置
  - 各ステージ: 初期化→読込→前処理→特徴抽出→変換→後処理→保存
  - 番号表示 + ステージ名
- **現在**: なし

#### **G. プログレスバー**
- **オリジナル**: 詳細なプログレス表示 + パーセンテージ
- **現在**: シンプルなプログレスバーのみ

### **3. スタイル・デザインの違い**

#### **色使い**
- **オリジナル**: `surface_sidebar: '#141416'` (より暗いサイドバー)
- **現在**: 統一された `surface_card: '#1C1C1F'`

#### **フォント設定**
- **オリジナル**: SF Pro Display + SF Pro Mono の使い分け
- **現在**: SF Pro Display のみ

#### **スペーシング**
- **オリジナル**: 超コンパクト（1-16px の細かい段階）
- **現在**: より大きめのスペーシング

### **4. 機能的な違い**

#### **出力設定**
- **オリジナル**: 
  - 出力ディレクトリ選択
  - ファイル名カスタマイズ
  - リアルタイムプレビュー
- **現在**: Enhanced mode表示のみ

#### **ピッチ調整**
- **オリジナル**: スライダー付きピッチ調整
- **現在**: なし

#### **ファイル選択表示**
- **オリジナル**: 詳細なファイル情報表示
- **現在**: シンプルなファイル名のみ

### **5. macOS固有の設定**
- **オリジナル**: macOS ダークモード強制、スケーリング調整
- **現在**: なし

## 📋 **修正が必要な要素**

### **優先度 HIGH**
1. ナビゲーションバーのアイコン + タイトル
2. 2カラムレイアウトの正確な再現
3. 横並び入力セクション
4. 2カラム設定セクション
5. ステージインジケーターの実装

### **優先度 MEDIUM**
6. 出力設定の完全実装
7. ピッチ調整スライダー
8. フォント設定の統一
9. スペーシングの調整

### **優先度 LOW**
10. macOS固有設定
11. 詳細なファイル情報表示

## **結論**

現在の実装は基本的なダークモードデザインは再現していますが、**レイアウト構造が根本的に異なって**います。特に：

1. **横並びレイアウトが縦並びになっている**
2. **専用の設定セクションが欠如**
3. **ステージインジケーターが未実装**
4. **サイドバーのスタイルが異なる**

これらを修正して完全に一致させる必要があります。
